Look up variables in our MI patient dataset (training set). Input one variable name or keyword, or several separated by commas (up to 20), for example "age, diabetes, potassium". For each one it returns the matching variables (up to 5 per term, or 8 for a single term) with: type, when it is known (admission or later), % missing, meaning, and its precomputed unadjusted link with heart failure. Returns "No variable matches" if the dataset does not have it. It only looks up results computed in advance; it cannot calculate anything new.
