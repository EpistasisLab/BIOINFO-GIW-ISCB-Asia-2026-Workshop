Look up variables in our MI patient dataset (1,700 patients). Input a variable name or a keyword, for example diabetes, potassium, or prior_heart_failure. Returns up to 8 matching variables with: type, when it is known (admission or later), % missing, meaning, and its precomputed unadjusted link with heart failure. Returns "No variable matches" if the dataset does not have it. It only looks up results computed in advance; it cannot calculate anything new.
